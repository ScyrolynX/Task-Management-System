About This Task System

What is this project?

This Student Task Management System helps students add, organize, and track their daily tasks in a simple and clear way.

You can:

  • Add tasks with optional due dates.
  • See tasks grouped as Today, Upcoming, Overdue, Completed, and Skipped.
  • Mark tasks as done, skip them, or delete them.

This is my first backend project using Flask and SQLAlchemy, built to practice real-world web app concepts like routing, forms, and databases.
